天强音乐 API

会员制 AI 音乐生成接口：账号有有效会员就能调用，不按次扣费。一次调用生成 2 首完整歌曲。

基础信息

Base URLhttps://pfamjwzbmpwskhsspcev.supabase.co/functions/v1/musicapi
鉴权平台账号登录后拿到的 Authorization: Bearer <access_token>（不需要申请任何 API Key）
数据格式请求与响应均为 application/json（UTF-8）
计费会员制：会员有效期内不限次调用，不扣次数、不查余额；会员过期返回 403
机器可读https://pfamjwzbmpwskhsspcev.supabase.co/functions/v1/musicapi/openapi.json（OpenAPI 3.0.3）
音频链接有效期约 1 小时。生成完成后请立刻把 mp3 转存到自己的存储，不要长期依赖原链接。

端点一览

GET /me查询会员状态与能否生成
POST /v1/music/generate生成音乐（会员有效即可）
GET /v1/music/task?id=xxx查询任务状态与音频地址

2 · 生成音乐

两种模式二选一：灵感模式用一句描述，自定义模式给歌词加风格。

gpt_description_prompt灵感模式：一句音乐描述，例如「温暖的城市民谣，木吉他，女声」
prompt自定义模式：歌词正文
tags自定义模式的风格标签，例如 lofi hiphop, mellow piano
title歌名，可选
mvchirp-goose（默认，最省）/ chirp-hawk / chirp-hawk-wild；不传按默认走，不必关心
make_instrumentaltrue 纯音乐，false 带人声
duration10–360 秒；不传由模型决定，不要传 null
negative_tags需要排除的风格，可选
curl -X POST https://pfamjwzbmpwskhsspcev.supabase.co/functions/v1/musicapi/v1/music/generate \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "gpt_description_prompt": "温暖的城市民谣，木吉他，女声",
    "make_instrumental": false,
    "title": "晚风里的你"
  }'
{
  "code": 200,
  "message": "success",
  "data": { "task_ids": ["a1b2c3d4-...", "e5f6g7h8-..."] }
}
返回的只是任务号。必须继续调用「查询任务」轮询，直到 status 变成 completed 才能拿到音频。

3 · 查询任务

curl -H "Authorization: Bearer <access_token>" \
  "https://pfamjwzbmpwskhsspcev.supabase.co/functions/v1/musicapi/v1/music/task?id=a1b2c3d4-..."
statusprocessing 生成中 / completed 完成 / failed 失败
result.custom_id歌曲唯一 ID，后续延长、翻唱、裁剪都用它
result.fileInfo.mp3UrlMP3 地址（约 1 小时有效）
result.proxy_url签名代理地址，优先用这个
result.fileInfo.cosUrl封面图地址
result.fileInfo.duration时长（秒）

轮询间隔建议 3–5 秒，不要高频空转。

错误码

401没带凭证，或 Key 无效 / 已停用 / 登录状态失效
403账号没有有效会员，data.tier 与 data.expires_at 可判断到期时间
400请求体不是合法 JSON、缺少必要参数或参数不合法
404接口路径不存在
502 / 503上游生成服务异常，可稍后重试；503 也可能是平台侧额度临时用尽

最小可用流程（JavaScript）

const BASE = 'https://pfamjwzbmpwskhsspcev.supabase.co/functions/v1/musicapi';
const TOKEN = '<access_token>';
const H     = { Authorization: 'Bearer ' + TOKEN };

async function makeSong(desc) {
  const res = await fetch(BASE + '/v1/music/generate', {
    method: 'POST',
    headers: { ...H, 'Content-Type': 'application/json' },
    body: JSON.stringify({ gpt_description_prompt: desc })
  });
  const { data } = await res.json();
  for (const id of data.task_ids) {
    for (let i = 0; i < 60; i++) {
      await new Promise(r => setTimeout(r, 4000));
      const t = await fetch(BASE + '/v1/music/task?id=' + id, { headers: H }).then(r => r.json());
      if (t.data?.status === 'completed') return t.data.result;
      if (t.data?.status === 'failed') throw new Error('生成失败');
    }
  }
}

凭证与会员

本接口不开放公众注册、也不需要 API Key。只用平台账号登录后拿到的 access_token：

const res = await fetch('https://pfamjwzbmpwskhsspcev.supabase.co/auth/v1/token?grant_type=password', {
  method: 'POST',
  headers: { apikey: '<平台 anon key>', 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'you@example.com', password: '你的密码' })
});
const accessToken = (await res.json()).access_token;

会员状态在服务端校验（按服务器时间），客户端改本机时间没有用；会员过期返回 403，去会员中心续费后立即恢复。
